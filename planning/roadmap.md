

# MACROmate Development Roadmap

This roadmap outlines MACROmate's development milestones and planned enhancements. Priorities may change as development progresses. 


## 1. Core Functionality - Implemented

- Configure daily calorie and macro goals.
- Add, edit, and delete Pantry foods.
- Add Pantry foods to Today's Meals.
- Edit meal quantities and remove meal entries.
- Clear Today's Meals without affecting Pantry items or configured goals.
- Calculate daily nutritional totals and remaining targets.
- Calculate maximum food quantities within remaining targets.
- Display daily macro progress and running totals.
- Persist application data using localStorage.
- Implement safeguards for editing and deleting referenced Pantry foods. 


## 2. MVP 1.0 - Remaining Development

### External Food API Integration

- Select and integrate an external nutritional data API.
- Implement food search.
- Allow users to import nutritional information into My Pantry.
- Handle API loading states, errors, and incomplete nutritional data.

External API integration is a requirement for the Codecademy portfolio project.

---

### Responsive Design and UI Refinement

- Review and refine mobile layouts.
- Adapt layouts for tablet and desktop screens.
- Review navigation, forms, modals, and interactive controls across screen sizes.
- Finalize visual consistency and usability.

---

### Testing and Release Preparation

- Test core user workflows and edge cases.
- Review accessibility, keyboard navigation, and feedback messages.
- Verify data persistence and application reset behavior.
- Address outstanding bugs.
- Prepare project documentation and README.
- Deploy MVP 1.0.

---


## 3. Post-MVP Enhancements 

### Meal Planning Suggestions

- Suggest food combinations using available Pantry items and remaining macro targets.
- Recommend food quantities in grams.
- Prioritize matching protein, carbohydrate, and fat targets.
- Indicate whether suggested food combinations fit within the remaining calorie target or exceed it.

---

### Additional Features to Evaluate

- Macro-priority filtering for food recommendations.
- Range-based macro goals.
- Expanded meal planning guidance.

These features are potential enhancements and not commitments for MVP 1.0.
